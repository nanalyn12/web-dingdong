# A-1-28. 예약·반복 생성 스케줄러

> 논문 부록 A-1 · 개발 프롬프트(표준화) · 웹앱 Dingdong

**목적** : 사람이 화면을 열지 않아도 정해진 때에 콘텐츠가 만들어지게 한다.

### 전제

① 콘텐츠 생성이 오래 걸리는 작업으로 관리되고 있다  
② 서버가 계속 떠 있다

### 프롬프트

```text
콘텐츠 생성에 예약과 반복을 붙인다.

- 서버 안에서 1분마다 도는 시계를 두고, 실행할 때가 된 예약이 있는지 살핀다.
- 예약은 시각과 요일로 지정하고, 판정은 [표준시]로 한다.
- 같은 예약이 같은 날에 두 번 실행되지 않게 마지막 실행 날짜를 저장한다.
- 키워드를 여럿 등록하고 차례로 돌려 쓸 수 있게 한다.
- 시계는 첫 요청이 들어올 때 한 번만 시작하고, 이미 시작되었으면 다시 걸지
  않는다.
- 서버가 다시 뜨면 진행 중이던 작업이 남는다. 시작할 때 그 작업을 실패로
  정리하고 사유를 이용자가 읽을 수 있는 문장으로 남긴다. 기다리던 작업이
  있으면 일꾼을 다시 깨운다.
- 정해진 시각에 도는 다른 일(야간 정리 등)도 이 시계에 함께 얹는다.
```

### 비고

별도의 작업 서버를 두지 않고 웹 서버 안의 시계로 처리하였다. 서버가 하나일 때에만 성립하는 방식이며, 여럿으로 늘리면 같은 예약이 여러 번 실행된다. 원자료에는 예약한 생성이 실패하였다는 보고가 여러 건 남아 있고, 시계와 복구의 처리는 코드에서 정리하였다.
